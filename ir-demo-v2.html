Technical Details

How It Works

The three core algorithmic components powering the hybrid ranking system.

📊
TF-IDF Scoring
TF(t,d) = freq(t,d) / |d|
IDF(t) = log(N / df(t))
TF-IDF = TF(t,d) × IDF(t)
Score(d,q) = Σ TF-IDF · cosθ
Term frequency measures how often a term appears in a document; IDF penalises terms common across all documents. Rare but frequent terms earn high weight. Cosine similarity normalises for document length. Vocab ≈ 12,400 stemmed terms.
🔗
PageRank
PR(u) = (1−d)/N
        + d · Σ PR(v)/L(v)
d = 0.85  |  tol < 1e−6
Convergence: ~18 iterations
Models a random web surfer following links with damping probability d, or teleporting uniformly. Pages with many high-authority inbound links earn high PR. Dangling nodes handled via uniform teleportation vector.
🔀
Hybrid Fusion
Score(d,q) = α · TF-IDF(d,q)
              + β · PageRank(d)
α = 0.6  |  β = 0.4
Tuned via 5-fold CV on NDCG@10
Linearly combines content relevance and link authority. α=0.6 keeps content dominant; β=0.4 lets PageRank boost authoritative pages. Grid-search over α ∈ {0.3…0.7} found α=0.6 optimal — yielding +42% P@10 and +34% NDCG@10.
